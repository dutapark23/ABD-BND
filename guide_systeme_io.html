Phase 02

Connecter le paiement (Stripe)

Durée estimée : 20 minutes · Nécessite une pièce d'identité
Pourquoi Stripe ?

Stripe est la solution de paiement intégrée à Systeme.io. C'est elle qui va recevoir les paiements de vos clientes et les virer sur votre compte bancaire. Gratuit à créer — Stripe prend 1,4% + 0,25€ par transaction.

1

Accéder aux paramètres de paiement

Navigation Tableau de bord Systeme.io → menu gauche → Paiements → Intégrations de paiement → Stripe
2

Créer un compte Stripe

Cliquez sur "Connecter Stripe". Si vous n'avez pas encore de compte Stripe, vous allez en créer un.

Informations requises Email · Nom complet · Adresse en France · Numéro de téléphone · Pièce d'identité (photo) · IBAN de votre compte bancaire
⚠️ Important : Stripe demandera une vérification d'identité. Préparez votre carte d'identité ou passeport en photo lisible. Le processus prend 24-48h pour validation complète.
3

Attendre la validation

Une fois le formulaire Stripe complété, revenez sur Systeme.io. Stripe apparaîtra comme "En attente de validation".

💡 La validation Stripe prend généralement 24 à 48 heures. Profitez de ce temps pour créer la formation (Phase 3).

✓ Checklist Phase 2

  • Compte Stripe créé
  • Pièce d'identité envoyée
  • IBAN renseigné
  • Stripe connecté à Systeme.io
Phase 03

Durée estimée : 1 à 2 heures
1

Navigation Tableau de bord → menu gauche → Produits → Formations → bouton "Créer"
2

Nommer la formation

À saisir Nom : Le Code Masculin
Description courte : "Comprendre les hommes pour ne plus souffrir — 5 semaines pour tout changer."
3

Créer les 5 modules

Dans la formation, cliquez sur "Ajouter une section" pour chaque module. Créez-les dans l'ordre :

Titre du fichier "Bonus — Les 10 vérités sur les hommes que personne ne dit"

2

Systeme.io propose des modèles de pages. Choisissez un modèle sombre et épuré.

Phase 07

Test final avant lancement

Durée estimée : 30 minutes · À faire AVANT d'annoncer
1

Faire un achat test

Systeme.io permet de simuler un achat en mode test sans vrai paiement.

Action Activez le mode "Test" dans les paramètres Stripe → faites un faux achat de l'Offre 2 (597€) → vérifiez que vous recevez bien l'email de bienvenue et que l'accès à la formation fonctionne.
2

Vérifier sur téléphone

Action Ouvrez la page de vente sur un téléphone. Vérifiez que tout est lisible, que les boutons sont accessibles et que les vidéos se lancent correctement.
3

Copier le lien de la page de vente

Systeme.io vous donne une URL pour votre page de vente.

Action Copiez ce lien — c'est lui que vous allez mettre dans la bio TikTok de @KarimPhoenix le jour du lancement.
💡 Le lien ressemblera à : karimphoenix.systeme.io/le-code-masculin — Vous pouvez aussi acheter un nom de domaine (ex: lecodemascutin.fr à ~10€/an) et le connecter à Systeme.io pour plus de professionnalisme.
