# Instructions pour Claude

## Mode de travail : toujours en équipe

Le propriétaire du projet demande que **chaque tâche, quelle qu'elle soit, soit traitée par une équipe d'agents**, pas par un seul agent.

Pour chaque demande :

1. **Découper** le travail en volets indépendants (ex. : recherche de données, analyse, rédaction, design / mise en page).
2. **Lancer des agents en parallèle** (outil Agent) pour chaque volet qui peut avancer seul.
3. **Toujours ajouter un agent de vérification** à la fin : il relit le livrable, contrôle chaque chiffre contre la source, et signale les erreurs avant l'envoi.
4. **Assembler** les résultats, corriger ce que le vérificateur a relevé, puis livrer.
5. Dans la réponse finale, **indiquer brièvement l'équipe utilisée** (combien d'agents, qui a fait quoi).

Même pour une petite tâche, prévoir au minimum un agent qui fait le travail et un agent qui le vérifie.

## Contexte du projet

- Documents en français, style maison : fichiers HTML + PDF à la racine (couverture noire, accents dorés #c8a96e).
- Thèmes : formations marketing, lancement de produits, contenu YouTube immobilier Dubaï.
- Le propriétaire n'est pas technique : réponses claires, orientées business, sans jargon.
